# 编辑器 UX / 选择模型改版计划（2026-11-01）

> 状态：**计划已记录，代码未改**。
> 目标：让素材/帧编辑更可维护、测试更可信、画面与操作区域不互相遮挡。
> 不引入 interface；唯一关系仍是 `Asset.positions`。

## 0. 总原则

- **画面归画面，信息归侧栏**：不在截图内部长期覆盖提示/坐标/图例。
- **同一语义只实现一次**：矩形/多边形框选、点击采样、区域重叠判断都抽成共享函数。
- **实时/位置帧语义显式化**：每个测试结果必须带 `frame_source`、帧 id、实际采样点。
- **向后兼容**：旧素材字段继续可读；新字段可缺省并推导。
- **先修可观察问题，再做数据模型扩展**。

## 1. 画面布局、位置帧详情、悬浮遮挡

### 现状问题

- `#canvas-wrap` 是 flex+overflow hidden，画布上方还有结果/日志窗口；
- `#screen` 只设 `max-width/max-height`，在窄高窗口下可能出现底部裁切；
- 结果/日志、提示、点击分布图例/状态分布在画布周围，容易遮挡或挤压画面；
- 选择位置帧后没有稳定的“帧详情”区域。

### 目标

1. 画布区域使用固定的 16:9 stage：

```text
#canvas-stage
  width = min(可用宽, 可用高 * 16/9)
  height = width * 9/16
  canvas 填满 stage
```

2. 任何画布尺寸变化（窗口缩放/侧栏拖动/面板切换）统一重算，不允许裁切。
3. 画布外放置：
   - 结果/日志窗口；
   - 位置帧详情；
   - 点击分布图例/状态；
   - 操作提示；
   - “当前点击位置”指示。
4. 位置帧详情放在图片侧栏的帧行下方/侧栏底栏，而不是画布上：

```text
#4 我的式神
分类：式神录
尺寸：1280x720
来源：capture
时间：...
文件：frame-4.png
大小：...
当前：是
关联素材：预设
```

5. 选中多个帧时显示“当前选择 #4”，信息只针对当前帧。

### 验收

- 常见窗口尺寸（1280x720、1366x768、1920x1080、窄窗口）底部最后一行像素可见；
- 画布内无固定 UI 覆盖（临时框选文案除外）；
- 截图与位置帧详情可同时看到，不互相遮挡。

## 2. 框选抽成共享选择工具

### 目标

把现有矩形 ROI / 操作区域 / 多边形逻辑抽成：

```text
SelectionTool:
  mode: rect | polygon
  target: roi | action
  points
  closed
  invert
```

共享行为：

- 起点/终点归一化；
- 多边形顶点新增/拖动/删除/闭合；
- bbox 计算；
- 命中测试；
- 反选状态；
- 最小尺寸校验；
- 鼠标/触控/取消。

只保留一套 canvas 事件处理，避免 ROI 和 action 两套逻辑分叉。

## 3. 反选 + 操作区域多边形

### 目标

- 识别区域、操作区域都支持：
  - 矩形；
  - 多边形；
  - 反选（invert，选择多边形外部）。
- 现有 `AssetDecl.roi`（识别边框）不能承载多边形绝对区域，因此：
  - `roi` 继续保存多边形外接矩形（兼容旧运行时）；
  - 新增 `action_polygon` / `action_invert`（或通用 `action_shape`）描述操作区域；
  - 识别侧沿用现有 `polygon` 掩膜语义，不把操作多边形混进识别掩膜。
- 运行时点击采样：
  - 多边形内随机点；
  - `invert=true` 时在外接矩形减去多边形后随机点；
  - 没有多边形时沿用矩形随机点；
  - `action_roi` 仍作为兼容/bbox。

### 验收

- 画一个多边形并反选后，保存能读回；
- dry-run 目标点落在有效区域（反选时落在外部）；
- 旧素材没有新字段仍可加载/运行。

## 4. 实时帧 / 位置帧测试语义

### 目标

每个测试请求显式带帧来源：

```text
live=1        使用当前实时帧（每次测试前强制抓新帧）
live=0/false  使用素材位置帧
```

规则：

- 实时开启：
  - 识别、点测、拖测、模板匹配、OCR 都使用**实时帧**；
  - 不允许使用旧缓存帧；
  - 结果记录 `frame_source=live` 与 `frame_seq`。
- 实时关闭：
  - 素材测试使用**位置帧**；
  - 单素材多位置时，逐个位置帧测试并分别返回结果；
  - 结果记录 `frame_source=position`、`frame_id`、位置序号。
- 页面/日志显示明确标签：

```text
[实时帧] #live
[位置帧] #4 我的式神
```

### 验收

- 实时开/关各跑一次，同一素材结果来源不同；
- 实时关闭时不再隐式用当前选中帧代替位置帧；
- 多位置素材能列出每帧通过/失败。

## 5. 点测/拖测固定点问题

### 根因（已审计）

- [app.js](D:/OAS-dev/oas-core/apps/oasd/ui/app.js) `testAssetClick` 直接使用 `boxCenter(action)`；
- `testAssetDrag` 起点也使用 `boxCenter`，只随机距离，X 固定；
- dry-run 没有复用 runtime 的 humanize 采样。

### 目标

抽出共享采样函数：

```text
sampleActionPoint(asset, rng) -> {x,y}
sampleDrag(asset, direction, rng) -> {from,to}
```

规则：

- 点击：在有效操作区域/多边形内随机，不固定中心；
- 拖动：
  - 起点随机；
  - 终点沿方向 + 横向抖动；
  - 终点仍落在允许区域/方向边界内；
- 每次测试记录 seed/采样点；
- dry-run 和真实 runtime 使用同一采样实现。

### 验收

连续 5 次点测/拖测，坐标应出现合理变化；
无论怎么采样，点都在操作区域/多边形的有效集合内。

## 6. 识别区域 vs 操作区域有效性判断

### 目标

测试结果增加：

```text
识别区域
操作区域
是否重叠
有效性
```

规则（拟）：

- 没有显式操作区域：操作区域=识别区域，有效；
- 有显式 `action_roi`/`action_polygon`：
  - 识别 bbox 与操作区域相交 → 有效；
  - 不相交但操作区域被标记为**独立操作区域** → 允许，但显示“独立区域”；
- 增加来源字段（拟）：

```text
action_source: "recognition" | "fixed"
```

- 旧数据：
  - `action_roi` 缺失 → `recognition`；
  - 存在但无法判断 → 保守推断为 `fixed` 或 `recognition`（需最终裁定）。

### 防错目的

防止“识别 ROI 很大，识别目标移动到旧操作区域外面，但仍用旧操作区域点击”的静默错误。

### 验收

- 识别框移动后如果不重叠且来源是 recognition，结果醒目提示无效；
- 用户显式固定操作区域时不误报，标为“独立操作区域”。

## 7. 素材拖动排序

- 前端素材列表支持拖拽排序；
- 后端新接口：

```text
POST /task/assets/reorder {task, ids:[...]}
```

- 顺序存 `assets.json` 的 items 数组顺序；
- 支持部分列表重排、非法 id 拒绝；
- 保存后刷新当前任务素材；
- 不做跨任务迁移。

## 8. 帧分类重命名

- 接口：

```text
POST /frames/category/rename {from,to}
```

- 把 `from` 分类下所有帧改为 `to`；
- 空分类/未分类处理规则：
  - `from` 不能是空；
  - `to` 为空则移动到未分类（需确认）；
- 同步更新：
  - 帧分类筛选；
  - 当前帧分类；
  - 帧列表分组；
- 冲突处理：直接合并到目标分类，显示影响帧数。

## 9. 实施顺序（建议）

### Phase A（先修可见问题）

1. 画布 16:9 fit + 结果/日志/提示移出画布；
2. 位置帧详情侧栏；
3. 点测/拖测 humanize 采样修复。

### Phase B（语义修正）

4. 实时帧/位置帧测试来源；
5. 识别/操作区域重叠校验（先显示，不阻断保存）。

### Phase C（选择模型）

6. 抽 `SelectionTool`；
7. 操作区域多边形 + 反选；
8. 旧数据兼容与回归。

### Phase D（维护操作）

9. 素材拖动排序；
10. 帧分类重命名。

## 10. 需要用户确认

1. 操作区域多边形字段命名：
   - `action_polygon` + `action_invert`；
   - 或统一 `action_shape` 对象。
2. `action_source` 是否作为正式字段写入 `assets.json`。
3. 实时关闭时：
   - 单素材多位置是**全部测**还是只测第一个位置帧。
4. 分类重命名 `to` 为空时：
   - 禁止；
   - 或移动到“未分类”。
