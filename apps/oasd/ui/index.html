动作库

          

          

            先选中中间的 if/loop/while 容器，再添加子动作；否则追加到根流程末尾。
          

          

            流程里引用变量（含「识别文字变量」）时，用属性面板的「插入变量 ▾」在
            text_expr / 条件表达式里写 param('key')（变量在构建页「变量」面板声明）。
          

          

            条件与等待：出现 = 现在有没有；识别 = 读出文字内容。
            「等到条件」是阻塞等待步骤：条件成立后继续执行下一个 flow 步骤
            （不会触发独立动作）；超时则本步失败。
          

          

            长按：按住定位对象的 hold_ms（默认 3000ms），可选随机范围拟人。
            曲线滑动（多段近似）：按 points 逐段滑动，每段是独立手势，App 可能视为多次滑动。
          

          

            操作区域素材：定位对象/拖动端点可指定整个素材库中的任一素材作为操作区域来源
            （仅「素材操作区域 / 最近匹配」模式，写 region.asset）；操作区域素材无匹配时本步会失败。

加入素材集合

    

      集合=多素材目标（模板/OCR 行/使用端OCR文字配置项/固定区域均可），flow 直接引用集合 id；
      成员按各自类型识别，region 成员=固定区域（总是命中，作为兜底）。
      同一素材只能属于一个集合（已在其它集合时会自动移出旧集合）；集合嵌套不支持。
